# GIDEON 0.2.3 — Windows kurulumu

Windows x64 dosyası **GIDEON-0.2.3-Kurulum.exe**. Yayınlanan dosyaya çift tıklayın; program Windows hesabınıza otomatik kurulur ve açılır. İlk kullanımda Gemini API anahtarınızı bir kez girip **Kaydet ve aç** seçin. Sonraki açılışlarda masaüstündeki **GIDEON** simgesini kullanın; büyük arşiv yeniden çıkarılmaz. Ayrı Node/OpenClaw kurulumu, terminal veya yönetici kurulumu gerekmez.

Önceki konuşmalar, notlar ve Windows hesabıyla şifrelenmiş anahtar `%APPDATA%\GIDEON` altında korunur. Veri klasörünü silmeniz gerekmez. Taşınabilir 0.2.1 ve kurulum 0.2.2 paketleri yayın kontrollerini geçemediği için yayımlanmadı.

Linux'ta **59 birim ve 9 entegrasyon testi** geçti. **Bu sürüm; gerçek kurulum, masaüstü kısayolunun hedefi, kurulu uygulamanın görünür arayüzü/ikinci açılışı/DPAPI şifreleme ve okuma/doğal kapanışı, standart kaldırma ve kişisel verinin korunması ile aynı paket içeriğinin Windows motor denetimleri geçtikten sonra yayımlanır.** Önceki çıkarılmış EXE'nin başarısı yeni kurulum kontrollerinin yerine geçmez.

Program yayıncı sertifikasıyla imzalı değildir. Gerçek Gemini yanıtı ve mikrofon/canlı ses testi yapılmadı. Google API erişimi ve kota gerekir; tüketici Gemini/ChatGPT aboneliği API ücretini otomatik karşılamaz.
