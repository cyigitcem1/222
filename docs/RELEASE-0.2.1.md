# GIDEON 0.2.1 — Windows açılış düzeltmesi

**GIDEON-0.2.1-Windows.exe**, ilk kullanımda veri klasörünü önceden hazırlar, başlangıç penceresini görünür açar ve arayüzün yüklenmesini bekler. Kullanıcının bildirdiği açılmama sorunu için eski ve yeni Windows dosyalarının karşılaştırmalı testi bekleniyor. Mevcut konuşmalar, notlar ve Windows hesabıyla şifrelenmiş API anahtarı korunur; veri klasörünü silmeniz gerekmez.

Windows x64 için taşınabilir tek dosyadır; Node ve OpenClaw içindedir. İlk kullanımda Gemini API anahtarınızı bir kez girip **Kaydet ve aç** seçin. API erişimi ve Google kotası gerekir; tüketici Gemini/ChatGPT aboneliği API ücretini otomatik karşılamaz.

Bu sürüm yayıncı sertifikasıyla imzalı değildir. **0.2.1 uygulamasının gerçek Windows pencere açılışı ve DPAPI kontrolü şu an beklemede.** Önceki Windows Node/Gateway testi bu kontrollerin yerine geçmez. Gerçek Gemini yanıtı ve mikrofon/canlı ses testi henüz yapılmadı.
