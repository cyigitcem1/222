# GIDEON 0.2.2 — Windows kurulumu

Önerilen Windows x64 dosyası **GIDEON-0.2.2-Kurulum.exe**. Çift tıklayın; program Windows hesabınıza otomatik kurulur ve açılır. İlk kullanımda Gemini API anahtarınızı bir kez girip **Kaydet ve aç** seçin. Sonraki açılışlarda masaüstündeki **GIDEON** simgesini kullanın; büyük arşiv yeniden çıkarılmaz. Node, OpenClaw, terminal veya yönetici kurulumu gerekmez.

Önceki konuşmalar, notlar ve Windows hesabıyla şifrelenmiş anahtar `%APPDATA%\GIDEON` altında korunur. Veri klasörünü silmeniz gerekmez. Taşınabilir 0.2.1 paketi Windows yayın kontrolünü geçemediği için yayımlanmadı; bu sürüm kullanıcı hesabına kurulan uygulamayı dağıtır.

Linux'ta **59 birim ve 9 entegrasyon testi** geçti. **Bu sürüm; gerçek kurulum, masaüstü kısayolunun hedefi, kurulu uygulamanın görünür arayüzü/ikinci açılışı/DPAPI şifreleme ve okuma/doğal kapanışı ile aynı paket içeriğinin Windows motor denetimleri geçtikten sonra yayımlanır.** Önceki çıkarılmış EXE'nin başarısı bu yeni kurulum kontrollerinin yerine geçmez.

Program yayıncı sertifikasıyla imzalı değildir. Gerçek Gemini yanıtı ve mikrofon/canlı ses testi yapılmadı. Google API erişimi ve kota gerekir; tüketici Gemini/ChatGPT aboneliği API ücretini otomatik karşılamaz.
